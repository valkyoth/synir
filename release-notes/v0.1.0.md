# Synir 0.1.0 — foundation candidate

Status: UNRELEASED. Pentest: PENDING. No tag or package publication authorized.

## Goal and delivered scope

Prepare a reviewable Rust workspace and roadmap. Four library/helper boundaries,
Rust-only dependency-free xtask, shared README branding, dual licensing, GitHub
CI templates and security/release policies. The supplied IDEA is preserved.

## Verification

See [setup verification](../docs/verification/setup.md) for commands and results.
Required gates: local checks; Rust 1.90.0–1.98.1; portable targets; deny/audit;
freshness; exact candidate pentest; hosted CI and CodeQL Default setup.

## Security impact

No third-party Cargo dependencies; unsafe code and build scripts prohibited.
Package graphs, source-size limits and no_std boundaries are checked. Tooling is
new security-relevant code; policy tests are not a pentest or an independent audit.

## Compatibility and limitations

No syntax API, real proc-macro expansion, lexer, Unicode data, or source editing
exists. Optional feature wiring is scaffold only. Cross checks do not imply device
execution. Hosted results and repository settings require verification on GitHub.
The full package family is not published; registry-name availability is unverified.

## Release evidence

Candidate commit, final pentest report, hosted checks, package archives and
checksums will be recorded when an actual release is prepared. No evidence is
invented to turn setup into a released version.
